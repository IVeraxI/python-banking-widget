# Виджет банковских операций

Учебный проект на Python для обработки и форматирования данных о банковских переводах клиентов.

## Функционал проекта

### 1. Маскировка данных (`src/masks.py`)
* Маскирует номера банковских карт в формате: `XXXX XX** **** XXXX`
* Маскирует номера счетов, оставляя видимыми только последние 4 цифры: `**XXXX`

### 2. Форматирование виджета (`src/widget.py`)
* Принимает строку с типом и номером карты/счета и правильно маскирует их.
* Преобразует и форматирует дату операции в привычный вид: `ДД.ММ.ГГГГ`

### 3. Обработка операций (`src/processing.py`) — *Новое!*
* **Фильтрация:** Находит операции по их статусу (например, только успешные `EXECUTED`).
* **Сортировка:** Упорядочивает список банковских операций по дате (от самых свежих к старым).

## Установка и запуск

Проект использует менеджер зависимостей **Poetry**.

1. Установите зависимости проекта:
```bash
poetry install
```

2. Для проверки стиля кода линтерами:
```bash
poetry run flake8 src/
poetry run mypy src/
```
## Модуль generators

Функции для потоковой обработки больших объёмов транзакций без загрузки всех данных в память сразу.

- `filter_by_currency(transactions, currency_code)` — возвращает итератор транзакций с заданной валютой.
- `transaction_descriptions(transactions)` — генератор описаний транзакций по одному.
- `card_number_generator(start, stop)` — генератор номеров карт в диапазоне в формате `XXXX XXXX XXXX XXXX`.

Пример:
\`\`\`python
usd_transactions = filter_by_currency(transactions, "USD")
next(usd_transactions)
\`\`\`

## Тестирование

Для запуска тестов используется библиотека `pytest`.

### Запуск тестов

```bash
python -m pytest tests/ -v
```

### Запуск с отчётом покрытия

```bash
python -m pytest --cov=src --cov-report=html -v
```

Отчёт покрытия сохраняется в папку `htmlcov/`.

### Модуль csv_excel_reader

Функции для чтения финансовых транзакций из CSV и Excel файлов.

- `read_csv_file(file_path)` — читает CSV-файл (разделитель `;`) и возвращает список словарей с транзакциями.
- `read_excel_file(file_path)` — читает Excel-файл и возвращает список словарей с транзакциями.
